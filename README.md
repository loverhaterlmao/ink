## What it is

A document editor that measures how text was written and says exactly what it measured.

**Open it:** [wrote.ink](https://wrote.ink)

Ink is made by Sick & Nexra Studios (S&NS). Its source code is closed. This repository is where to find it, how
to get help, and where to report problems.

<!-- v2:b -->
## The desktop app

<img src="./assets/app.svg" alt="Ink for Windows on its start screen" width="100%">

- **Getting it:** [the latest release](https://github.com/loverhaterlmao/ink/releases/latest). Unzip it and open `Ink.exe`. There is nothing to install.
- **What it is:** a window onto [wrote.ink](https://wrote.ink). Your work stays in your account on the site; the app keeps only your sign-in, in a folder beside itself.
- **What it needs:** Windows 10 or 11. It uses the WebView2 runtime, which Windows 11 has built in.
- **The warning Windows shows:** "unknown publisher", the first time. The app is not code-signed yet. Check the file's
  SHA-256 against the one in the release notes if you want to be sure it is ours.
